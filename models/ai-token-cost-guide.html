How much does a million AI tokens cost?

There is no single price. An API bill depends on the model, how many tokens you send and how many it generates. Calculate input and output separately, then add them.

The basic calculation

For ordinary text requests without caching or extra tool charges:

Cost = input tokens ÷ 1,000,000 × input rate + output tokens ÷ 1,000,000 × output rate

Use rates quoted per million tokens in the same currency. A million input tokens and a million output tokens are two separate quantities, not one million total.

A worked example

These are invented rates for learning the calculation, not a provider quote: $2 per million input tokens and $8 per million output tokens.

What counts toward your bill?

  • Input: the material supplied in a request. Repeated conversation history and documents can add to the input count.
  • Output: generated tokens. For OpenAI reasoning models, billed output can include internal reasoning as well as the visible answer.
  • Cached input: reused input may have a different rate. Use the provider's reported breakdown; do not charge the same cached tokens again as ordinary input.
  • Other charges: tools, storage and non-text media may have separate prices. Batch and service tiers can also change the applicable rate.

Estimate a real workload

  1. Run a small sample of the tasks you expect to repeat, and record the provider's reported input and output usage.
  2. Calculate each task's cost at the applicable rates. Include retries and additional model calls.
  3. Multiply the average task cost by the number of tasks you expect. Compare several samples if task lengths vary.
  4. Check the provider's usage dashboard against the estimate before scaling up.

Are tokens the same as words?

No. Token counts depend on the model and language. A word-count shortcut is only an approximation; use the model's tokenizer or reported usage for a closer estimate. Counting input alone cannot predict output length.

What about a monthly subscription?

A chat-plan fee is not a per-token API rate. Check the plan's API billing and any separate credits before including them in your budget. See our ChatGPT Plus and Claude Pro comparison for subscription billing context.
